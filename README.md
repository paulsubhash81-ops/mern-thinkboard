# 🧠 ThinkBoard - MERN Stack App

## 📌 Overview
ThinkBoard is a full-stack MERN application that allows users to create, manage, and organize their thoughts/notes efficiently.

---

## 🚀 Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB

---

## 🏗️ Architecture

The project follows a typical MERN architecture:

Client (React)
⬇️
API Layer (Express + Node.js)
⬇️
Database (MongoDB)

### Flow:
1. User interacts with UI (React)
2. API request sent to backend
3. Backend processes request
4. Data stored/retrieved from MongoDB
5. Response sent back to frontend

---

## ✨ Features

- Create notes
- Edit notes
- Delete notes
- Responsive UI
